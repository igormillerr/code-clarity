# CodeClarity 0.4.0

Плагин Codex для ревью читаемости **зафиксированных Git-изменений Java и Python**.
Он сначала сохраняет независимое ревью исходников, затем сопоставляет замечания
с шестью метриками и формирует отчёты JSON/Markdown. История ревью хранится
в проверяемом репозитории; предложения правил остаются в статусе `PROPOSED`.

**Установка и обновление: [INSTALL.md](INSTALL.md).**

В комплект входят:

- MCP-сервер **0.1.7** в `server/codeclarity-mcp.jar`, Java-зависимости
  и Python worker уже внутри JAR.
- Launcher `scripts/LaunchMcp.java` и проверка настройки `scripts/setup.py`.
- Четыре Skills: `readability-review`, `independent-review`,
  `metrics-correlation`, `rule-discovery`.
- Контракты JSON и средства сохранения, проверки и отображения отчётов.

Нужны локальный Codex с поддержкой плагинов, **JDK 21+, Git, Python 3.10+**
и `complexipy==8.3.0` из `requirements-python.txt`. Maven и Node.js пользователю
не требуются. JDK и Python не включены в архив. Локальный stdio-сервер работает
на компьютере, где запущен Codex; облачный Codex и браузерный ChatGPT не получают
доступ к нему от одной установки этого архива.

Пример запроса после установки и настройки:

> Используй CodeClarity / readability-review для ревью Java- и Python-изменений
> между main и HEAD. Сначала прочитай исходники и зафиксируй независимое ревью,
> затем получи метрики. Сохрани итоговые JSON и Markdown в .codeclarity/reviews.
> Явно укажи пропуски анализа и ограничения.

Замените `main` своей базовой веткой. Проверяются Git-коммиты;
незакоммиченные изменения не входят в это сравнение.
